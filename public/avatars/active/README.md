# Active runtime Avatars

Only files used by the WebXR runtime belong here.

- `performers/`: Ch02 female and Ch06 male, 16 animation clips, 1024px maximum
  texture size.
- `audience/`: four distinct seated characters, one sitting idle clip each,
  256px maximum texture size.

The `.runtime.json` files record the reproducible optimization profile and
resulting clip list. Full Mixamo builds remain in local-only `local_assets/`.

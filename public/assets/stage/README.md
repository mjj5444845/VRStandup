# Stage assets

这里仅保存运行时真正使用的轻量 GLB 舞台资产。模型来自仓库根目录忽略上传的 Kenney 素材包，授权信息见同目录两个 `LICENSE.txt` 文件。

- `chair.glb` / `chair-rounded.glb`：观众座椅
- `bench.glb` / `loungeChair.glb`：观众区休息家具
- `tableRound.glb` / `stoolBar.glb`：舞台桌凳
- `speaker.glb`：舞台音箱
- `plantSmall1.glb` / `pottedPlant.glb`：舞台绿植
- `floor-thick.glb` / `column.glb` / `stairs.glb`：舞台结构
- `Textures/colormap.png`：上述 Kenney GLB 引用的共享色板，部署时必须随模型一起保留

不要把原始素材压缩包提交到 Git；需要新增模型时，只提取页面实际引用的文件。

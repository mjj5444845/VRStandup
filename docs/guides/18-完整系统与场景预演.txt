完整系统与 Soft Clay Club 场景预演
更新：2026-11-03；Windows 11 已做自动检查。Mac/Quest 完整场景集中验收。

一、不需要头显的查看方式

Vercel 部署成功后，打开系统首页中的“先参观 Soft Clay Club 并体验完整预演”，或访问 /study/demo。
首次会载入约51MB公开模型、字体和声音；等待场景就绪。填写工程前测，点击“启用声音并播放”，完成练习及四轮评分、后测，下载记录与完整性报告。
桌面抓取/放大/松开等按钮只在相应条件及花字出现期间可用。工程动作为合成动作与节拍，不是正式演员内容。
页面保持前台；切换后台或明显画面停顿会保护性暂停，按提示恢复。本机浏览器预演记录刷新后不会保留，请先下载。

二、实验室完整双端预演

在项目根目录，Windows PowerShell：
  npm.cmd ci
  npm.cmd run check
  npm.cmd run build
  npm.cmd run lab:start

Mac终端使用同样命令，但 npm.cmd 改为 npm；Mac本批实际运行结果以CI及集中验收分别记录。
打开 http://127.0.0.1:3002/lab/session，使用服务生成的本机密钥文件；不要把密钥发到聊天或放进公开网页。
点击生成完整工程配置，选“完整工程流程”；按需要选择实验录音。创建新工程场次后，按页面信息在 /study/session 配对参与者。
若要求录音，参与者先点准备实验麦克风并自行确认权限，再按页面就绪。启动后按实际问卷和播放结果推进，无需人工模拟“播放完成”。
实验员可暂停、恢复或中止。录音保存失败会保留副本，可以重试或下载。结束后下载报告/CSV；终态可做本机校验备份。
当前工程素材编号以 club-flow- 开头，避免覆盖以前的占位素材。实际分配表、真人片段及正式问卷另行审核，正式研究仍保持关闭。

三、资产与数据在哪里

公开运行副本：public/study/club/v1/，包括已选用模型、花字、字体和人群音效，manifest.json 可核对SHA-256。
本机完整源包：local_assets/collections/soft-clay-club/v1/，保留原文件、源件和全部预览；不必为正常运行重新导出。
需要重新从本机源包生成运行副本时：node scripts/prepare-club-assets.mjs；先另建资产版本再改变外观，不覆盖已确认原件。
实验数据：data/sessions/；私密表演素材：local_assets/performances/；默认本机备份：backups/sessions/。
备份应再复制到独立介质并验证；同机副本不能代替独立备份。

四、本轮不需要立即做头显操作

集中检查清单：docs/project/DEVICE_TESTS.md。
重点包括完整负载帧率、坐姿视线/穿椅、中文问卷、双手输入、D回应、真实麦克风和物理同步。
遇到资产404或版本不符，检查部署版本及manifest，保留错误记录，不删除真人原件或绕过浏览器安全提示。

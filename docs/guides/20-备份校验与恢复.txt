实验室会话备份：校验与恢复
更新：2026-11-03。软件使用临时合成会话测试，未破坏真实研究数据。

一、创建备份

在实验室 /lab/session 中选已正常结束或中止的工程场次，执行“备份本机记录”。
默认副本保存到 backups/sessions/场次-时间/；里面包含 backup-manifest.json 和逐文件校验值。
把整份副本复制到独立介质后再校验。软件校验成功只说明该副本内容一致，不证明介质独立或断电安全。

二、在 Windows PowerShell 校验

在项目根目录运行，将示例目录替换为实际备份：
  npm.cmd run lab:backup -- verify "D:\实验备份\场次-时间"

成功时输出 verified: true。清单缺项、多出文件、文件损坏、链接或路径不安全时明确失败，不继续恢复。
不会打印录音或问卷内容。

三、恢复到新目录

停止要恢复使用的实验室服务，再运行：
  npm.cmd run lab:backup -- restore "D:\实验备份\场次-时间" "D:\VRStandup\data\restored-sessions"

工具会在新的会话根目录下新建原场次编号。原编号已经存在时拒绝覆盖；不会与现有场次混合。
只复制通过哈希校验的文件。恢复到备份自身内部、公开目录、归档或源码目录都会被拒绝。
随后用恢复目录启动检查：
  npm.cmd run lab:start -- --data "D:\VRStandup\data\restored-sessions"

先核对原终态、日志和报告、录音校验，再决定是否使用该副本；不自动续播或更改身份密钥。
访问密钥文件沿用指定实验室的 --access 配置，备份会话不意味着跨电脑公开凭据。

四、Mac

在Mac终端使用 npm run lab:backup，npm.cmd改为npm，目录替换为实际绝对路径。
恢复工具已纳入Mac/Windows自动检查；独立介质和真实断电验收单独记录。

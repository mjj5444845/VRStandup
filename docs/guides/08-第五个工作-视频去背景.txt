PunchCap：视频去背景检查
更新：2026-11-03

方案更新：用户已确认采用三维虚拟演员的动作与声音预录回放。
本页保留为视频技术检查参考，去绿幕不再是正式演员主线的前置要求。
当前方案见 docs/design/PERFORMER_RECORDING.md。

一、用途与当前范围

去掉视频中的绿色背景，保留主体，专业上叫“色键抠像”。
这是 M0 的 S4 独立检查，尚未接入正式剧场或实验流程。
可以对照原片与三维画面、调整边缘，也可以读取本机视频。
本页始终静音；声音同步继续在 /spike/media 检查。

原创样片由代码绘制，不是真实演员，也不能证明头发细节已经合格。
Mac 样片功能通过，不等于 Windows 或 Quest 3 已通过。

二、Mac 打开方法

在项目根目录的终端执行，每行输入后回车：

npm ci
npm run check
npm run build
npm run spike:net

已安装且 package-lock.json 未变化时，不必重复 npm ci。
浏览器打开：http://127.0.0.1:3001/spike/chroma
如果 3001 已在提供最新构建，可以直接打开页面。
若端口被占用，先在原启动窗口按 Control + C 停止，再重新启动。

三、Windows 11 打开方法

在项目根目录的 PowerShell 中执行：

npm.cmd ci
npm.cmd run check
npm.cmd run build
npm.cmd run spike:net

浏览器打开同一个本机地址：http://127.0.0.1:3001/spike/chroma
依赖与构建必须在 Windows 本机生成，不从 Mac 搬 node_modules 或 .next。
播放仓库里现成的样片不需要安装 FFmpeg。

四、检查步骤和成功标志

1. 等待“视频已就绪”，点击“播放”。
   左侧显示有绿幕的原片，右侧显示深蓝背景上的主体。
   绿色应消失，主体与下方的浅色、灰色和红色色块仍能看见。

2. 调整“去除范围”。数值越大，去掉的颜色越多。
   若调得过大，人物也会消失；点击“恢复默认参数”恢复。

3. 调整“边缘柔和度”和“边缘去绿”。
   前者控制透明过渡，后者减轻半透明边缘上的背景色反光。
   绿色衣服本身也可能被抠掉，不能靠调参数恢复原本相同的背景色。

4. 把底色从深蓝切到浅灰、近黑，观察边缘有无绿色残留或破洞。
   点击“暂停”后仍可调参数；右侧应立即更新。

5. 展开“查看参数与显卡检查”。
   原创默认参数在本次 Mac 检查中读得透明度 0 / 255 / 255 / 93。
   0 为透明，255 为不透明，最后一个色块验证柔和边缘。
   其他设备的最后一项允许有少量取整差异；页面会按参考计算核对。
   此检查只验证默认参数的算法，不判定实际演员效果。

6. 点击“选择本机视频”。建议使用 H.264 编码的 MP4。
   文件仅由当前浏览器读取，不发送到服务器，也不保存到项目目录。
   从原片选择实际背景颜色，再小幅调节参数。真实参数需另记来源与录像条件。
   点击“使用原创样片”可以切回来；选择同一个文件也能重新读取。

7. 点击“重新加载预览”，再点击播放；也可以返回音画同步，再次进入本页。
   应始终只有一份三维画面，旧画面停止播放并释放资源。

五、头显检查（待实际验证）

Quest 3 的 USB 连接已于 2026-11-03 恢复；本色键页尚未在头显或真人素材上验收。
Windows 原创样片、参数、底色与默认显卡色块已检查，本轮不改变证书信任或防火墙。
后续按 05-第二个工作-HTTPS与头显连接.txt 准备同网 HTTPS 地址。
在头显浏览器打开：https://实验室电脑IP:8443/spike/chroma
先播放样片，再点“进入 VR 查看”，检查透明边缘和颜色，最后退出 VR。
普通电脑没有 VR 设备时，进入按钮灰色属于正常情况。
本机文件不自动出现在头显里；需要在头显本地另行准备素材，不能把 Mac 的本机路径填入头显。
本页不验证“一次点击同时开启声音、视频和 VR”；那是后续 S5。

S4 完整验收必须使用实际演员录像，并在桌面和头显分别观察：
人物边缘无明显绿边、头发不缺失、两边颜色一致。
记录设备、浏览器版本、录像来源、最终参数、绿边/发丝/颜色观察结果。
失败时保留记录，再讨论离线抠像的退路，不自行宣称通过。

六、常见问题

只有空底色：先恢复默认参数，确认原片能播放，并确认去除颜色与原片背景一致。
视频打不开：检查文件是否为浏览器支持的编码；扩展名为 mp4 不代表里面一定是 H.264。
出现绿色边缘：先检查原录像布光，再小幅调整；不要为了去边缘而把人物一起抠掉。
预览无法创建或中断：重新加载预览，记录浏览器、显卡和错误文字。
Mac 正常、Windows 异常：在 Windows 重新安装与构建，并保留当地错误，不用 Mac 结论替代。

七、重新生成原创样片（可选）

日常运行不需要这一步。需要修改样片时，先另存现有文件，再使用明确来源的本机 FFmpeg。
生成脚本遇到已有成品会停止，不自动覆盖；勿把真人录像当作原创样片覆盖进去。
Mac 命令：npm run spike:chroma-fixture -- --ffmpeg "本机FFmpeg完整路径"
Windows 命令：npm.cmd run spike:chroma-fixture -- --ffmpeg "C:\工具目录\ffmpeg.exe"
重新生成后需要核对 fixture.json、更新资产来源并重新检查。

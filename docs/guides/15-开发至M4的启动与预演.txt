开发至 M4：正式模块启动与工程预演
更新：2026-11-03

适用与当前范围

Windows PowerShell 使用 npm.cmd；Mac 使用 npm。源码共用，依赖和构建需在本机生成。
已提供 M2 规则、M3 录制/私密素材整理/复查、M4 服务和双端流程预演。
正式研究尚未开放：最终分配/题目/预评分依据、真实资产、M5–M9 与集中设备验收仍需完成。
工程按钮模拟媒体/问卷完成，不收集真实答案，不能当参与者已经看完或作答。

首次准备

1. 在项目根目录执行 npm.cmd ci（已有依赖且锁文件未变时不必重复）。
2. 执行 npm.cmd run check，再执行 npm.cmd run build。
3. 生成本机工程样例：npm.cmd run assets:rehearsal。
   样例在 local_assets/performances/，草稿配置在 local_assets/config/rehearsal-plan.json。
   这是原创程序动作与节拍，不是演员录音；已存在的原件不覆盖。
   本机若已经生成配置，无需重复生成；校验使用 npm.cmd run assets:verify。
4. 执行 npm.cmd run lab:start。
   默认只监听 127.0.0.1:3002，使用生产构建；开发模式用 npm.cmd run lab:dev。
5. 打开 http://127.0.0.1:3002/lab/session。
   密钥保存在 data/lab-access.json；在控制台选择该文件或复制其中 operatorKey。
   程序不把原始密钥打印进日志，也不把它保存到浏览器待发队列。

配对与预演

1. 实验员连接后，读取本机工程预演配置，或导入自己已校验的配置 JSON。
2. 选择参与者去身份编号，填写唯一场次编号，创建“工程预演”。
3. 在第二个浏览器/窗口打开 http://127.0.0.1:3002/study/session。
   输入场次及控制台给出的参与者配对密钥，不要把实验员密钥给参与者。
4. 参与者点“确认准备完成”；实验员推进到前测。
5. 参与者依次确认预演前测、练习；实验员开始每轮，参与者确认主片段和轮后问卷。
6. 四轮之间由实验员推进；第四轮后参与者确认后测，场次结束。
7. D 条件的回应只能在配置窗口内、同段最多两次；预演中可手动调整标注清楚的工程进度，再触发回应、确认回应完成。
8. 可暂停、恢复、保存备注或填写原因中止。已结束场次不能继续推进。
9. 下载事件记录供本机核查。所有实验日志在 data/sessions/，工程自动测试另用临时或 output/ 目录。

断线和失败

断线会暂停会话并清除就绪状态，客户端自动重连；不会自动继续。
重连后由参与者重新确认就绪，再由实验员恢复。
未确认指令先写本机待发队列，收到服务端持久保存回执后才移除；同一指令补发不重复执行。
旧版本操作可能被拒绝，需要看最新状态后重新操作；不会悄悄改写原指令。
磁盘写入未确认时保留队列并提示；先检查存储并重启服务，再重试未确认指令。
同场次另一浏览器不能冒用身份；确需换浏览器时，由实验员解除绑定并使用新的配对密钥。
日志损坏或尾部未写完整会拒绝恢复并保留原件，不自动删掉尾部假装成功。
时钟结果为网络时间估计，保存往返与不确定度；不是声学、屏幕或头显姿态物理同步通过。

HTTPS 与 Quest（统一实机时执行）

本轮不要求戴头显。集中验收时，已授权的 USB 转发可使用 3002 端口和 Quest localhost。
局域网需要可信证书及对应 IP/域名：
npm.cmd run lab:start -- --host 0.0.0.0 --port 3002 --cert certs/lab-cert.pem --key certs/lab-key.pem
服务拒绝在无 TLS 时向局域网开放；不自动安装信任、修改防火墙或绕过警告。
角色密钥仍然需要；USB localhost 不等于已经验收 LAN 证书信任。

其他入口

/record：正式录制、本机原件导出、旧原件读取、几何目标及候选 GLB 复查。
/lab/assets：私密片段库、校验、新版本、片段审核；需要实验员密钥。
/lab：原准备工具保留；/study：原浏览器准备保留；/spike：历史技术验证入口继续保留。

停止

在服务终端按 Ctrl+C，等待日志和连接关闭。不要直接删除会话目录或覆盖原件。
集中实机项目逐项记录在 docs/project/DEVICE_TESTS.md，素材准备清单在 docs/design/ASSET_REQUESTS.md。

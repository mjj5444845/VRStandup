# 身体、表情与口型：当前可行性和决策范围

本机 Soft Clay Club 候选资产已有51骨骼、6段制作动画、3个表情形变。此结论来自本项目模型节点和动画重读；真实录制目前提供头部、双手和声音。当前播放器准确驱动这三路，缺失时隐藏对应表面。

| 选项 | 现有输入与可独立完成的部分 | 需要决定或实际确认的部分 |
| --- | --- | --- |
| 头手直接驱动 | 已实现比例、朝向、审核偏移、缺失保护与世界坐标一致性，自动检查通过 | 腕部偏移、身高/位置、真实录制与显示同步 |
| 手臂两段IK | 已实现可选两段几何估算候选；设备测试页可切换，仅对工程素材启用，保留原始头手记录 | 无肘追踪，肘部弯曲方向是估算；是否用于研究及穿模可接受范围须确认 |
| 全身估算 | 可使用头高和候选站姿/坐姿构造身体动画 | 腿、腰、脚没有被头显直接采集，不能把估算叫全身实录；演员体型和风格须确认 |
| 制作表情 | 已交付眨眼/微笑/张嘴形变及对应制作动画 | 没有真实面部捕捉，播放何种表情可能影响观看条件，需要内容审核 |
| 声音驱动张嘴 | 可从声音能量做开合示意 | 单一张嘴形变不等于音素口型；是否需要自然口型、追加形变/采集和研究条件影响须决定 |

当前保持已明确的头手主方案。未把可选手臂候选、全身或声音张嘴加到正式播放，也未用程序合成表演替代真人。后续若选择某项，另立版本并用同一真实片段比较；先保留原件、再保存估算层与其来源，避免混入实录数据。

手臂候选已有骨长、弯曲方向、超出可达范围、缺失追踪、开关复位及实际GLB驱动测试；估算层不写回原始头手数据。全身/表情/口型采用何种输入与表现仍须确定方案，不能凭现有三路姿态补成实录。

# 演员录制与异步回放

## 已确认的观看方式

演员提前在实验室使用 VR 设备表演，记录动作和声音。
之后，三维虚拟演员在剧场里重演，观众从各自的座位观看。
观众转头或改变观察位置时，看到的是同一个三维演员的相应角度。

这属于“动作录制与回放”。录屏保存的是某个视角的画面，不能直接作为三维动作数据使用。
当前主方案不要求绿幕、演员视频面板或逐帧视频手部标注。

## 先录什么

第一版计划先验证头部、双手的位置与朝向，以及演员声音。
选用手柄还是裸手、采样频率和具体录音格式，需在真实录制验证时确定。

| 内容 | 记录与处理原则 |
| --- | --- |
| 头部 | 保存头显提供的姿态与时间，不能将观众的视角用于驱动预录演员 |
| 双手 | 优先验证设备实际提供的输入姿态，保留左右手身份、能力和有效性 |
| 声音 | 保存原始录音及其与动作起点的对应关系，不能仅凭同时按按钮就认定同步 |
| 追踪异常 | 记录缺失、估算、输入设备变化和参考空间重设，不能填成全零后当正常动作 |
| 校准 | 保存地面、演员原点、朝向、身高/模型比例与录制到舞台的转换 |
| 模型 | 保存版本与动作映射，保证同一段素材在不同回放中表现一致 |

WebXR 的输入姿态可能不可用，也可能包含估算位置；手部关节属于另外的可选能力。
实现时以[WebXR Device API](https://www.w3.org/TR/webxr/)和[Hand Input Module](https://www.w3.org/TR/webxr-hand-input-1/)为依据，并记录设备实际结果。

全身、面部表情和口型尚未确定采集方案，不能假设戴上头显后就自动全部录到。
若用头和手的位置推算身体，专业上叫“逆向运动学（IK）”；推算姿态必须与实际采集数据区分。

## 录制阶段

1. 选择演员编号和模型，记录设备、浏览器与软件版本。
2. 校准地面、舞台正前方、演员站位和模型比例。
3. 确认输入有效、麦克风可用，由演员明确操作开始录制。
4. 保存带时间戳的动作、声音及两者时间对应关系。
5. 停止后检查素材是否完整，记录中断、异常和有效时间范围。
6. 在回放预览中复查，确认后把这一段列入可使用素材清单。

前期原型使用独立的 punchcap-recording-check-v1；正式模块只在转换时读取它，不将其直接当作正式素材清单。
2026-11-03 的集中开发已新增正式模块 v1：原件 punchcap-take-v1，片段清单 punchcap-clip-v1，保留独立原件与审核版本。
正式录制入口为 `/record`，私密库为 `/lab/assets`；旧检查格式只在明确的转换入口读取，不作为正式模块依赖。
180 秒与文件/模型上限是工程资源保护；录制上限写入原件，不代表真实长录制或物理同步已验收。
节点映射和 GLB 预览已实现直接头手驱动；未知身体、表情和口型不标作实录。操作见[素材整理审核](../guides/16-演员素材整理与审核.txt)。

## 回放阶段

1. 读取同一片段的模型、动作、音频和校准信息。
2. 把录制空间转换为舞台空间，保持动作比例和朝向。
3. 按音频播放进度采样动作，在相邻采样之间插值，驱动演员。
4. 观众自由转头观看，观众视角变化不改变录制演员的动作。
5. 暂停、续播和回应切换时，同时处理声音、动作和花字时间线。
6. 结束或离开页面时释放模型、声音和监听资源。

头部和双手姿态不是完整的人体模型。接入正式带骨骼模型时，需要额外检查动作映射、身体推算与穿模。
第一版即使用简单几何体验证，也不能把它记作正式演员已制作完成。

## 花字与回应

写意花字跟随回放中的三维手部或模型锚点，加上明确的空间偏移。
间离花字按研究时间线出现；不再使用视频画面中的二维位置。

回应也提前录制动作和声音，使用同一演员及兼容的模型与校准信息。
播放回应前记住主片段进度，回应结束后同步恢复；是否过渡动作、如何衔接姿势，需要专门验证。
条件限制、回应窗口和次数上限继续按系统指南执行，不能改成未计划的实时演员连线。

## 当前最小验证

已提供独立 `/spike/replay` 检查页，使用程序生成的 12 秒头部/双手轨迹和原创节拍声。
操作见 [三维动作与声音回放](../guides/09-第六个工作-三维动作与声音回放.txt)。
这是测试片段格式，尚未冻结正式录制格式。
目标是确认读取、按时间重演、暂停、继续、重播、切换观察视角和资源清理正常。
轨迹和音频需有明确可核对的同步标记，记录实际误差与测量方法；验收阈值另行确定。

2026-11-03 新增独立 `/spike/record`，操作见 [真实录制检查](../guides/13-真实动作与声音录制检查.txt)。
Quest 3 已完成中文校准、真实头部/双手柄/麦克风采集、导出、回放和重新读取回放。
首份约 8.74 秒、786 帧，三路姿态全部有效，48 kHz 单声道声音无削波；这次为手动停止。
后续自动结束复测为完整 15 秒、1350 帧、720000 个声音采样，结束原因为 limit、无中断，三路姿态全部有效。
动作以 AudioContext 采样起点计时，并另存 XR 预测显示时间和观察时间。
记录地面原点、朝向和头部高度；尚未拟合人体模型比例。
使用 AudioWorklet 保存连续 PCM，依据 [Web Audio](https://www.w3.org/TR/webaudio/#AudioWorkletGlobalScope) 与 [媒体采集规范](https://www.w3.org/TR/mediacapture-streams/)。
麦克风输入延迟与 XR 姿态预测尚未标定，共用时钟不能证明物理同步达标；正式指标仍待确认。
原型有中断和缺失记录、文件校验与本机回放；自动停止已实测，异常路径与裸手仍需逐项实测。
第二批已实测取消准备、系统菜单中断、部分片段回放、重新准备和同页连续录制，说明见 [中断检查](../guides/14-录制中断与重新开始.txt)。
无回复时只保留已收到的连续声音，标记尾部不完整并截齐动作时间；该回退有软件组合测试，不能写作硬件麦克风拔插已通过。
头部或双手的估算位置标记仍保留；中断后的新录制必须重新校准，不自动续接旧文件。
模拟数据只验证程序，不证明真实采集、麦克风延迟、动作完整性或头显性能达标。
完成基础闭环后，再逐项加入完整模型、表情、口型和预录回应。

## 素材保存

原始动作、声音、校准和带身份的资料默认放在本机，不自动公开或上传。
演员录制资料与观众实验记录分开管理，文件清单使用去身份编号。
只有确认可以公开的模型和示例素材才进入 `public/study/` 并登记来源。
录制与回放正式格式、私密素材托管、设备能力和同步指标仍待验证。
当前已有正式录制、本机原件导入、私密素材库与头手/候选 GLB 复查；完整剧场中的正式演员播放器属于 M5，仍待真实资产与集中验收。

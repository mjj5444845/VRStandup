# ADR-0008：三维场景使用 Three.js

## 背景

系统指南指定 Three.js；用户再次明确新版使用 Three.js。
环境说明需要分清基础工具与三维画面工具的用途。

## 决策

- 使用官方 `three` 包制作新版三维场景与交互，代码放在 `study/xr/`。
- 初始安装版本为 `three@0.186.0`、`@types/three@0.186.0`，固定准确版本。
- Next.js 承载网页和实验员控制台；Three.js 负责页面中的三维部分。
- 头显连接使用浏览器的 WebXR 能力，按 M0 完成真实设备验证。
- 新版不引入旧演示的 A-Frame 渲染方式。

## 理由与放弃的方案

遵循指南 ADR-0008 和用户指定的技术选择，直接控制画面、视频和交互。
保留现有网页工具链，继续按小步骤开发，不在环境安装阶段扩展完整场景。

## 后果

渲染代码在浏览器运行，统一管理更新循环和资源释放。
依赖安装成功只表示工具已准备好，不能代替网页渲染或头显验收。

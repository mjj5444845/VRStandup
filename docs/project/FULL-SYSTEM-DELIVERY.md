# 完整工程流程与 Soft Clay Club 接入

日期：2026-11-03。用户要求先完成替代资产的软件闭环，随后接入已制作的整套候选，自动检查后上传。本批合并交付这两部分。正式研究仍关闭。

## 可用入口与流程

- `/study/demo`：浏览器内完整工程预演，无需密钥。前测、12秒练习、四轮、条件后问卷、后测、报告下载。动作与节拍为合成测试内容；不会自动上传参与者记录。
- `/lab/session`：在实验室服务生成完整工程配置、配对场次，接入真实播放器、问卷和测量；支持暂停、中止、断线恢复、报告/CSV和终态备份。
- `/study/session`：参与者凭场次与密钥连接实验室；片段与实验录音经认证接口读取/写入私密目录。Vercel 仍引导进入实验室地址，持久服务没有迁往云端。
- `/record`、`/lab/assets`：沿用录制、整理、校验与审核入口。正式内容必须重新审核，工程样例不冒充真人表演。

## 软件与资产

M5：统一 Three.js 帧循环、WebXR、音频主时钟、模型/图片/字体加载与释放。运行时加载原创 `scene-empty`、演员和五种观众；四桌各三椅加后排十二椅，24个座位逐一核对 GLB 与设计表。隐藏当前座位的观众；其余23位使用独立骨架及共享几何材质。重复静态网格实例化，减少重复绘制。照明使用暖色半球光与舞台方向光，不为每个灯具增加动态阴影。

演员使用 Soft Clay Club v1 的 Head/LeftHand/RightHand，按录制参考头高缩放并统一转向观众；花字和视线测量使用同一世界坐标。追踪缺失时隐藏对应蒙皮表面。身体保持制作原型，未实现真实全身捕捉、自然IK或音素口型。当前完整场景仅支持该候选映射，不会默默把别的模型当成它播放。

M6–M7：八款原创花字 PNG 按明确资产编号载入；显示/过期/锚点、条件限制、抓取、双手拉伸、投掷、舞台落点与自身挂载已接通。D允许窗口内落到舞台会切到已登记回应，最多两次；结束后恢复主片段进度。工程样例使用两款花字和一个测试回应，其余资产供配置使用。真实回应语义及姿态衔接需要演员审核。

M8：桌面及 VR 中文问卷、答案范围/必填/版本检查，三维头姿采样、视线角度、来源和追踪缺失记录；性能采样记录刷新率/帧数/经过时间；实验麦克风由明确操作启用，播放期间分段录制。未确认保存的副本保留供下载或重试。问卷、媒体、回应和录音标记统一轮次与片段上下文。

M9：真实 WS/HTTP 流程、持久日志、场后完整性报告与 CSV、文件重读校验、终态备份和新服务恢复。备份副本逐文件核验，但同一台电脑的备份不等于独立介质验收。未进行3–5人预实验。

## 公开与私密范围

`public/study/club/v1/` 只选用26份运行文件，共50,714,642字节：7个GLB、8张花字PNG、6份人群音效WAV、中文字体/OFL、演员映射、布局与照明说明。另有来源及哈希清单。原始本机总包36模型、源件、预览、原始声音和生成工具继续留在 `local_assets/`。真人声音/动作、会话、密钥、证书和备份不上传。

公开入口保持分工：GitHub Pages 看板仅发布看板运行文件；Vercel 用户入口包含公开展示资产。公开模型仍是候选版本，来源登记见 [ASSETS](../../public/study/ASSETS.md)。

本机 Windows 统一自动检查、GLB实际解析、骨架/坐标/动画/资源释放、真实服务完整流程及生产构建结果见 [VALIDATION](VALIDATION.md)。Node模型测试对图片解码做测试替身，只验证结构与资源生命周期，不证明像素外观或GPU表现。

集中实机项目见 [DEVICE_TESTS](DEVICE_TESTS.md)。尚待研究配置、真人表演与回应、物理同步、全身/口型决策、Quest/Mac完整负载、领夹麦、独立介质备份和3–5人预实验；上述外部验收没有自动勾选。

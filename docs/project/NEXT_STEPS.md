# 下一步工作

更新：2026-11-03。M5–M9 工程软件流程已接通，Soft Clay Club 候选资产已接入运行场景。自动结果与设备/研究验收分别记录，见 [交付范围](FULL-SYSTEM-DELIVERY.md)。

1. 先在Quest打开 https://vr-standup.vercel.app/study/device ，按12项提示完成并下载总报告；PC可以演练与复查。集中检查当前整场：座位、通道、视线、人物穿椅、光照、花字中文、双手交互和实际刷新率。按 [实机清单](DEVICE_TESTS.md) 保存证据，不要求用户反复卡准秒数。
2. 用正式 `/record` 录制真人练习、四组主段子和回应；整理到私密素材库，核对头手比例、腕部偏移、缺失追踪、动作声音物理同步与回应衔接。当前合成动作与节拍继续明确标注。
3. 研究负责人确认条件顺序、段子组匹配/阈值、正式问卷与评分版本。将审核配置导入后才考虑打开正式研究；草稿题目及工程顺序不能直接当作正式依据。
4. 检查实验麦克风实录、数据对齐、异常恢复和独立介质备份；根据实测决定灯光、模型与动画的进一步优化。可选手臂估算候选已提供；全身、表情与音素口型另作需求决策，见BODY_OPTIONS.md。
5. 在设备和内容满足条件后安排3–5人预实验，记录问题再修复；不能用自动模拟场次代替真人预实验。

本机完整资产源包已经交付，正常运行不再需要重新找一轮基础家具/人物资产。缺失的旧参考包原件与真实演员内容仍需补齐。资产来源与剩余确认项见 [资产清单](../design/ASSET_REQUESTS.md)。

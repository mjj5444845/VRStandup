## 统一执行顺序

1. 先确认研究配置和素材清单的版本，保存测试前工作区及原始文件。
2. 本机启动正式服务，检查 H00 和身份配对，不改已有证书信任/防火墙设置来绕过错误。
3. 做 H20–H27 的录制与回放，按片段保留成功和失败记录。
4. 做 H30–H33 的会话、断线和重启，用预演场次及测试目录，避免污染真实研究。
5. 有最终模型、剧场与问卷后补 H01–H03、H26、H28、H34；不能提前勾选。

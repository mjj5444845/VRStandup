# 分模块推进计划

这份文件说明先做什么、后做什么。当前完成程度见 [状态文件](STATUS.txt)，
具体操作见三份平台说明，代码细节见 [系统指南](../design/SYSTEM_GUIDE.md)。
首页将本计划拆成可搜索的任务看板，详细数据见 [任务清单](tasks.json)。
每项分别记录归属、作用、完成意义、实际进展、完成标准与前置工作；Mac 通过与完整交付分开统计。

## 已确定的安排

- Three.js 制作三维场景，Mac 开发，Windows 11 实验室电脑运行。
- 演员在实验室使用 VR 预录动作和声音，之后由三维演员异步回放；观众从各自座位观看。
- 旧版归档，新版重新建立代码、舞台和视觉方案；素材按需复制并登记。
- 先准备环境、确认本机能打开网页，再进入技术验证。一次只做一个小任务。
- Windows 与头显分别实测，不能用 Mac 通过代替。

## 模块顺序

M 是阶段编号，不是命令。下表是开发目标，不表示已经实现。
准备阶段的第一个代码任务为 `/spike` 三维显示检查；具体操作见 [04-第一个工作-三维显示检查](../guides/04-第一个工作-三维显示检查.txt)，
实际结果见 [检查记录](VALIDATION.md)。它是独立的本机显示验证，不代替 M0 的真实设备验收。
第二个代码任务为 M0 S1 的 HTTPS 与头显检查，操作见 [05-第二个工作-HTTPS与头显连接](../guides/05-第二个工作-HTTPS与头显连接.txt)。
检查服务与页面已经实现，Mac HTTPS 请求通过；Windows 和真实头显尚待验收，S1 仍未通过。
用户已决定暂缓 Quest 3 连接调试，继续能在本机完成的 S2。
第三个任务提供同端口的网页与测试消息，操作见 [06-第三个工作-两个网页传消息](../guides/06-第三个工作-两个网页传消息.txt)。
Mac 两页收发已验证；Windows 和头显结果继续待测，不据此跳过完整 M0 验收。
第四个任务为 S3：音频主时钟与视频跟随，见 [07-第四个工作-声音与视频同步](../guides/07-第四个工作-声音与视频同步.txt)。
采用新生成的测试素材；Mac 本轮 60 秒、最大偏差约 36.0 毫秒通过，Windows 和头显仍待测。

## 模型精修计划

剧场参考包已归类，详见 [建模参考](../design/SCENE_REFERENCE.md)。以下均为待完成任务，按顺序逐项验收。

| 顺序 | 工作 | 安排与完成标准 |
| --- | --- | --- |
| 1 | 整理空间与模型中心 | M5 场景接入前完成；统一朝向、尺寸、分组和摆放点，核对 24 个座位，保持既定布局 |
| 2 | 制作一把精细样椅 | 先确认软垫、椅背、椅腿及布料/皮革材质，座高与占地符合空间基线；确认后再复用到全场 |
| 3 | 细化墙面与地面 | 补充砖墙、护墙板、木地板和收口，纹理比例统一，保留门洞、通道和视线 |
| 4 | 完善灯光 | 舞台主光、观众暖光、壁灯和桌灯逐项设置；模型、花字可读且头显性能达标 |
| 5 | 增加装饰 | 完善幕布、地毯、海报、音箱和控制台，避免遮挡演员与交互区域 |
| 6 | 接入正式演员模型 | 先验证头部和双手驱动与模型比例，再检查身体推算、穿模；表情与口型单独验证 |
| 7 | 导出并实机检查 | 登记模型和贴图来源，导出 GLB；在 Mac、Windows 与 Quest 3 核对外观、布局、帧率和资源清理 |

精修依托可运行的回放与场景骨架逐步开展，先验证样例再扩展全场。它不代替 M0 的技术与真实设备验收。


## 哪些模块要等待前一步

M3、M4 都依赖 M2。M5 依赖 M3 和 M4。M6 依赖 M5，M7 依赖 M6。
M8 依赖 M5，M9 依赖 M7 和 M8。技术上允许分别准备的模块，仍按用户节奏逐项处理。

M2 从最简单的部分开始：数据类型和条件规则表 → 轨迹插值 → 时间线 → 配置校验 →
实验分配 → 通信协议 → 会话状态机 → 问卷定义。

## 仍需确认的研究依据

- 实验分配的具体顺序，需要与实验室研究方案一致。
- 条件后 VR 问卷不能直接用现有前后问卷替代，需要确认题目和量表。
- V12 的段子组预评分阈值及数据格式尚未确定，不能自行填写数值。
- 头显型号、浏览器版本、帧率和音画偏差必须实际记录。

技术验证依赖在对应验证开始时按需安装，已经安装的工具不重复安装。
临时验证代码使用 `study/spikes/` 与 `app/spike/`；正式模块不自动导入它们。
旧视频方案的二维轨迹 V8 与视频素材规则不直接沿用；按三维格式重新映射，研究时间窗与条件规则继续保留。

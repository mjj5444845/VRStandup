# ADR-0010：归档旧版，以新系统替代当前工程

> 这是归档发生时的决策记录，不是当前操作手册。后续清理已将根目录原始指南改成阅读入口，
> 原文仍保存在归档中。当前工作规则见根目录 `AGENTS.md`，完成状态见 `../project/STATUS.txt`。
> 本文“不参与部署”指新版不引用归档且运行产物不含归档；不表示将源码交给托管平台时平台无法读取归档，具体边界见 `../guides/SETUP.md`。

## 背景

2026-10-30，用户明确当前文件夹结构属于旧版，要求旧内容保存、新内容重新开始；
素材允许按需复用，舞台素材、资产配置和视觉效果使用新的方案。
这替代原指南中的“与旧演示共存、旧文件冻结”的实施安排。

## 决策

1. 旧应用、公开素材、服务、工具、文档、原始视频及输出移入
   `archive/legacy-2026-10-30/project/`，保持相对目录关系。
2. 旧工程配置与原始研究文档复制入归档。根目录研究指南与问卷继续保留。
3. 已有构建缓存单独保存在 `archive/legacy-2026-10-30/generated/`。
4. 当前根目录继续使用 Next.js/React/TypeScript 工具链，页面和研究代码重新建立。
5. 新系统不加载旧代码或资产。舞台、布局、灯光、材质、效果和资产配置重新制作；
   具体旧素材被选用时，复制到 `public/study/` 并记录来源与许可。
6. 原指南其余研究架构、条件定义、数据要求、技术验证与里程碑依赖继续适用。

## 理由与放弃的方案

根目录承载新版，使当前开发对象明确；归档保留可查阅和恢复的旧内容。
未采用继续维护两个运行系统的方案，因为用户已明确要求重新开始。
保留可用的框架版本和工具链，不将其视为旧版舞台或视觉设计。

## 后果

- 原指南目录白名单及五文件追加限制不再适用于此次重启。
- 归档不参与类型检查、静态检查、构建或部署。
- 移动及复制的源文件均以 SHA-256 在 `manifest.json` 中记录并核验。
- 大体积原始素材和缓存仍为本机资料，需要单独备份，Git 不包含完整本机归档。
- 当前仅有页面和模块骨架，M0、M1 均未完成。

# ADR-0011：采用三维演员录制与异步回放

## 背景

2026-10-30，用户补充演员可能提前在实验室使用 VR 录制片段，并明确选择：
“三维虚拟演员：记录动作和声音，观众能从自己的座位观看”。
这替代当前指南里“演员只能线上参与，因此用绿幕视频面板”的前提。

## 决策

- 正式演员采用预录动作和声音驱动的三维虚拟模型，观众在三维剧场中从自身视角观看。
- 录制与观众实验分开进行；录屏视频不能代替动作数据，正式主线不依赖色键抠像。
- 保留 Three.js、WebXR、实验室服务、音频主时钟及原有研究条件；动作、声音和花字共用片段时间线。
- 花字锚点改为三维回放的手部、头部或舞台位置，替代旧二维视频标注方案。
- 先验证头部、双手与声音；全身、表情、口型和具体设备能力在实测后逐项确定。
- 已实现的视频同步和色键检查保留为独立技术记录，不记作三维演员录制回放已通过。

## 理由与放弃的方案

满足用户明确选择的实验形式，允许观众按自己的座位与视角观看三维演员。
不继续将演员在家录视频作为唯一素材来源，不将虚拟演员的录屏冒充三维动作记录。
没有要求实时连线；表演片段与回应均可以事先准备。

## 后果

- 替代原指南 ADR-0001 中演员视频面板与线上录制的选择，以及 ADR-0009 中二维手部锚点的选择。
- 录制格式、模型驱动、校准、动作与声音同步、素材校验和性能负载需要重新验证；不自行编造设备能力或误差阈值。
- M3、M5、M6 和回应流程按三维素材调整，M0 增加录制回放检查；原 S4 不再作为正式演员主线前置要求。
- 视频方案原文单独保留，当前设计见 [系统指南](../design/SYSTEM_GUIDE.md)和[演员录制与回放](../design/PERFORMER_RECORDING.md)。
- 本次只调整设计与计划，未实现录制器、三维演员播放器或新模型。

# 花字视频标注协议

版本：annotation-2.0；更新：2026-11-04。概念依据以[花字概念](../design/CAPTION_CONCEPTS.md)为准。

## 范围与单位

范围为用户提供的36段本地视频。v1.0共483条事件、665个组件；本轮在既有候选事件及证据上逐条复审。此轮“全量复审”不意味着逐帧完整听看原视频，也不宣称发现了所有极短效果。

一条事件为表达同一意思的一次连续呈现。重新出现另记，用系列编号关联。图文分组件，组件起止仍继承父窗口，精确入场时刻待另标。原视频、粗标表、原PDF及既有v0.1／v0.2／v1.0保持。

复看发现的观察遗漏或误读另写`observation_correction_v2`、`visible_text_v2`、`visible_graphic_v2`及必要的`start_v2/end_v2`；不覆盖旧字段。组件中的字体颜色／描边／字符轨迹等若重复描述同一文字，保留旧行并标“归并为样式属性”；同一问号同时被写入文字和图形时也不重复计有效组件。原组件行数与复审有效组件数分开报告。

## 三层信息

| 层 | 保留内容 | 禁止混淆 |
| --- | --- | --- |
| 观察 | 文件版本、起止估计、台词／字幕语境、实际文字与图形、位置、变化、完整关键帧及五帧序列 | 台词语境不是完整逐字听写；编辑配字不是当事人真实心理 |
| 解释 | 写意等级及类型、表征对象、表演协同、联想空间、间离证据、歧义与变更理由 | 解释不冒充原指南原文、独立人工复核或已验证喜剧效果 |
| 提案与筛选 | 改编建议、锚点、渲染／时机缺口、参考候选决定、下一步 | 改编建议不回填成原片已有动作；参考入选不等于正式刺激批准 |

## 每条必填的新字段

- `xieyi_level_v2`：核心写意、扩展写意、边界待核、未见写意。
- `xieyi_types_v2`：W1物件指代、W2行动与过程、W3空间与情境、W4角色与形象、W5身体与心理状态，可多选。
- `represented_target_v2`、`performance_link_v2`、`imagination_gap_v2`：分别回答表现什么、怎样与表演协同、观众补足什么。依据不足写明不足。
- `jianli_status_v2`：有间离候选、边界待核、未见间离；另记手法和具体依据。
- `semantic_mode_v2`：由两轴归纳的显示分类。两轴明确成立为混合，任一明确成立则相应候选；均不成立且有未决轴为待判，其余为普通。
- `legacy_mode_v1`、`review_change_v2`、`review_reason_v2`：保留旧判断，说明是否因扩展定义或证据修正改变。
- `screening_v2`、`screening_reason_v2`、`next_action_v2`：参考候选、改编储备、边界复核、普通参照、不纳入当前参考库。不得删除未入选原记录。
- `evidence_review_v2`、`reviewer_v2`、`human_review_v2`：记录实际复审手段、Codex单一标注者、人工未复核。

## 复审次序

1. 先读原片语境和可见变化，再看关键帧与前后序列；有疑点时回到附近采样帧。
2. 独立检查写意三问。W5须指向具体状态并与表演协作；泛化星光、爱心、边缘光不自动升级。
3. 独立检查间离：新增的评价／立场是什么？若只是台词复述或普通状态提示，允许从旧间离降级。
4. 组件分别记录作用，支持写意的图形与支持间离的文字可能有不同结论。本轮组件说明参照父事件语境，精细的分组件独立证据及逐帧时长仍待后续复核。
5. 记录旧新差异，再筛选用途；不按目标比例调标签，不用理论扩展替代证据。

## 筛选口径

| 决定 | 条件 | 后续 |
| --- | --- | --- |
| 参考候选 | 写意／间离依据可说明，证据可定位，能提供具体设计关系 | 进入演员共创候选；仍须核对声音、时机与可读性 |
| 改编储备 | 原片功能可解释，但完整替换、密集动画、遮挡、资料引用等需较大改编 | 先写改编方案，再决定是否制作 |
| 边界复核 | 主要语义或表演协同证据不足 | 定向回看／听核及人工讨论；未决的轴不计明确成立，另一已明确的轴仍可保留 |
| 普通参照 | 当前只承担复述、说明、身份提示或装饰 | 保留作对照和反例 |
| 不纳入当前参考库 | 包装、解释笑话、无可识别增量或与当前目标无关等有明确原因 | 保留记录及排除理由，后续可重新决定 |

独立写意轴、间离轴允许重叠，各自占比不能相加为100%。显示分类五类互斥；W1–W5细类允许多选；筛选决定互斥。三种统计单位分开报告。

## 证据与质量限制

原起止约有0.25–1秒采样误差，不用两个小数位暗示帧级精度。台词依据烧录字幕及本地ASR辅助，尚未逐字听校；音效、笑声起点和包袱前停顿仍待听核。

本轮复审由同一Codex标注者完成，不能称为第二位标注者验证，不能计算标注者间一致性。复审完成状态与人工审核状态使用不同列。

原粗标表49行保持原文：38行有本地对应，另11行网络参考保持未匹配，除非取得对应视频证据。原视频与PDF复制件校验、主键、父子关系、截图链接、旧新计数及Excel公式联动均需检查。

本机材料留在忽略的`outputs/`，不进入`public/`；正式参与者记录仍只进入`data/sessions/`。本轮不自动导入正式刺激或开放研究模式。

局部时段修正仍沿用原事件ID，在新字段记录阶段；父事件窗口不得当作每个组件连续出现时长。例如SHORT023-E26的风线分两段出现，需按阶段复核，不能按整个父窗口累加为图形持续时间。

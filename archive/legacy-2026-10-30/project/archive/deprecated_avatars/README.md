# Deprecated Avatar Archive

This is the fixed archive for assets that must no longer be loaded by the app.

- `legacy_obj_2026-08-31/` contains the original eight OBJ/MTL avatars. They are
  kept only for research history and retain their original license.
- `legacy_idle_fbx_2026-08-31/` contains obsolete local FBX animation files. The
  binary contents stay on this machine and are ignored by Git.

Do not reference this directory from A-Frame. Active runtime models live only in
`public/avatars/active/`.
